The Ecosystem

Shared roots, three canopies

Everything grows from two shared systems. Every platform reads the same identity, the same wallet of coins, the same location context, the same notification center.

Shared Root · id.agri.in

AgriID

Universal identity. Mobile OTP first, OAuth2 + PKCE single sign-on across all domains. Internal UUID never exposed; public @handle everywhere. One profile, one location context, one session control.

Shared Root · Rewards

AgriCoins

Closed-loop loyalty ledger — append-only, idempotent, audit-proof. Earn across any platform, see one balance everywhere. Never cash, never transferable, always accountable.

▲ one identity · one wallet · one inbox · one location ▲
Hub · agri.in

Agri.in

The all-of-agriculture platform: 34+ verticals from seeds and tractors to schemes, land, labour, loans, mandi and weather. Discovery, leads, knowledge, community.

Dairy · milk.in

Milk.in

Pincode-first milk discovery — every brand and local vendor in your area, every milk type, subscription-intent leads routed to vendors. Platform never touches the milk money.

Organic · theorganic.in

TheOrganic.in

Organic brands, certified products and producers. B2C discovery with where-to-buy routing; B2B RFQ engine matching buyers to verified suppliers.

The Versatile Core

8 engines, built once

The 34 categories are not 34 features. Each is a configuration of one of eight engines — so adding a new vertical is a registry entry and a spec schema, not a rebuild.

E1~60% of verticals

Directory

Companies, shops, labs, vets, FPOs, warehouses — profiles, branches, geo search, verification, claim flow, reviews.

E2spec-schema driven

Catalog

Products with per-vertical spec sheets. Filters, comparisons and facets render automatically from admin-defined schemas.

E3moderated

Classifieds

User listings with a full lifecycle — livestock, land for sale or lease. Discovery and contact only, never payments.

E4two-sided

Matchmaking

Structured intents matched on category × geo × attributes: labour ↔ farms, loads ↔ transporters, trade leads.

E5verified data

Data / Info

Schemes, subsidies, loan and insurance tables, helplines, mandi prices — sourced, dated, human-verified reference data.

E63 languages

Content

Blog, news, guides, webinars and events — tagged by vertical and geo so content surfaces where it's relevant.

E7expert-flaired

Community

Forum with Q&A mode, accepted answers, verified expert badges, coin rewards and a serious moderation queue.

E8no payments

Booking-Inquiry

Soil tests, water tests, consultations, warehouse space — request, confirm, track. Providers settle directly.

Data protection as the first priority
