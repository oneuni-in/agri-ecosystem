# /market/today/{pincode}: read-only Today payload (weather+mandi+
# schemes+calendar) behind the agri_today flag (404 when off).
# Reference-data class like /catalog/verticals: no user data, no
# mutation, strict 6-digit path validation. A-U2 W1 made the weather
# half real (Open-Meteo via a per-pincode cache); the pincode is the
# only input and it is already public on every directory URL. W2/W3 made
# mandi, calendar and schemes real too — no fixture data is served here.
/market/today/{pincode}
# /market/commodities and /market/commodities/{slug}: the mandi commodity
# pages' data (A-U2 W3). Public records — commodity names, market names and
# published prices, all already public on agmarknet.gov.in — with no user
# data and no mutation. Bounded by the curated commodity set; the detail
# read is capped to a 30-day window. Deliberately NOT behind agri_today:
# that flag is the HOME strip's kill switch, and pulling indexed SEO pages
# out from under Google is a different decision from hiding a home section.
/market/commodities
/market/commodities/{slug}
# /content/feed and /content/items/{slug}: the E6 content engine's reader
# surface (A-U3 W1). APPROVED items only — the gate is structural, in
# service._published(), so no handler can widen it. Same read-only
# reference class as /catalog/verticals: editorial/news content that is
# already public at its source, with no user data and no mutation. A
# pending, rejected or nonexistent slug all 404 identically, so the
# public read cannot enumerate the moderation queue. Bookmarks are NOT
# here — they are per-user and private by SecureRouter default.
/content/feed
/content/items/{slug}
# /content/advisories: live pest advisories for a district (A-U3 W2).
# Approved items only, and additionally window-bounded — an advisory
# outside its dates is not served at all. Same public reference class as
# /content/feed. An unknown/absent location returns nationwide advisories
# only, never a guess.
/content/advisories
# /market/helplines and /market/schemes (A-U3 W2): published government
# helpline numbers and scheme cards. Public records already printed on
# official sites — no user data, no mutation — each carrying the source
# and verified-on date the UI renders. /market/schemes is the SAME read
# the home spotlight uses, so page and home can never disagree.
/market/helplines
/market/schemes
