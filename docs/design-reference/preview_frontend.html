Why it's built this way — one UI for the illiterate farmer and the affluent buyer

  • Icon + English + mother tongue on every tile. A person who can't read still recognizes 🚜 + color; a person who reads Tamil reads Tamil; everyone lands in the same place.
  • Nothing hidden. No hamburger menus. All 34 categories sit on the homepage in labeled groups — scroll is cheaper than discovery.
  • Voice first-class, not a gimmick. Big orange mic in search, "Ask AI" as the center bottom button, and needs can be spoken ("1 litre cow milk daily") instead of typed.
  • Call > chat > form. Every vendor card leads with 📞 Call and WhatsApp — the two actions every Indian phone user already knows. Forms are the fallback, never the front door.
  • Trust made visible. ✔ Verified and cert badges everywhere, "verified 2 days ago" stamps on schemes, ★ Sponsored always labeled — the affluent user checks certificates, the cautious user checks the tick.
  • Location does the filtering. Pincode is the universal Indian address literacy — one 6-digit number personalizes weather, mandi, milk, shops and schemes.
  • Big tap targets, high contrast, short words. 44px+ buttons, one idea per card, numbers before adjectives (₹55/L · 1.2 km · ★ 4.7).
  • Same account, same coins, same design language everywhere — learn one site, you've learned all three.
