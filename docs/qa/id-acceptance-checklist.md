# AgriID acceptance checklist (ID rows)

ID-U1 per the build prompt §3. **Rows are appended by later passes, never
rewritten.** A row goes ✅ only with evidence — a committed proof pair in
`docs/design-reference/id/proofs/`, a named test, or a recorded live run —
never by assertion. Deltas and their reasoning live in
`docs/qa/id-visual-log.md`.
